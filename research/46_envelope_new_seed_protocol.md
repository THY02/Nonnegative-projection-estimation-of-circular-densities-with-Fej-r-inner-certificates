# 折内上界惩罚：新随机样本独立验证方案

记录日期：2026-10-27；本记录在此次模拟运行之前写出。比较规则是在已见旧480样本和局部惩罚结果后确定，虽使用新随机种子，不是盲法预注册，也不构成外部真实数据验证。

固定新随机种子 2026102723；依照既有模拟的六类分布及顺序、样本量100和500，各10组新样本，共120组；用 numpy `SeedSequence([2026102723, scenario_index, n, rep])` 生成，各组随机五折，均为等大小折。网格 r={0,1,2,3,4,6,8,12}、η=0.1、最大 D/r=256；所有方法共用相同折内候选并使用相同五折得分，最终输出选中 r 的五个折内密度平均，而非全样本重拟合。

预定比较三项：（1）无惩罚五折；（2）确定性上界 A_j=(r_j+1)/(2π) 的原理论惩罚；（3）N=257节点与二阶余项给出的训练折自适应上界惩罚，比例ρ=1。令 t=log(5J²n²)、m=n/5，三个准则分别为 CV 分数、CV 加 2tA_j/(3m)、CV 加 2t平均折内上界/(3m)。自适应上界按 `min(A_j,[max_nodes q + (π/N)²Σℓ²|a_ℓ| + 1e-12]/(2π))` 计算，采用浮点数，不构成严格向外舍入保证。

记录每个案例全部40次折内拟合的参数、求解诊断和频率系数、全部8个候选评分及两种惩罚、三种选阶和 ISE；按案例记录任何候选或求解失败，不删除失败折继续选择。若存在失败，分别报告所有尝试数和失败数，均值仅是成功条件下结果。结果按场景、样本量和方法报告每格10次的 MISE、MCSE、相对无惩罚及相对固定惩罚的配对差和 MCSE、所选 r=0 与 r=12 的比例。按生成规则、已保存系数重新生成样本和折，独立重算候选分数、局部上界、选阶、ISE、摘要及输入哈希。评估中用真实密度 Fourier 系数至 256 阶，κ≤20 的尾项可忽略，截断尾不影响同组方法差值。

这只是每格10次的探索性新随机种子数值核查，不声称统计显著、方法普遍更准或数学上有限精度严格认证。已有数据及其观察结论与新运行明确分开保存。
