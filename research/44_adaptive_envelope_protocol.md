# 使用折内候选上界的惩罚：事后敏感性方案

日期：2026-10-27。本方案在观察理论惩罚可能过度保守、并完成已有 ρ 敏感性结果之后写成；复用原 480 样本、五折、8 个候选、已保存的全部折内系数与验证评分，不新增随机样本，也不是盲法验证。

对于每个归一化非负 r 阶候选 (g_{k,j}=q_{k,j}/(2\pi))，取 N=257 个等距节点，令

\[
A_{k,j}=\min\!\left\{\frac{r_j+1}{2\pi},\
 \frac{\max_{0\le h<N}q_{k,j}(2\pi h/N)+
 (\pi/N)^2\sum_{\ell=1}^{r_j}\ell^2|a_{k,j,\ell}|}{2\pi}\right\},\qquad
p_j^{\rm loc}=\frac{2t}{3mK}\sum_{k=1}^K A_{k,j}.
\]

在精确算术下，后一项来自对连续全局最大点和最近节点的二阶 Taylor 余项，在所有阶次满足 N>2r；无论候选是否严格正，这个上界对有限阶三角多项式有效。前一项是非负密度的确定性 Fejér–Riesz 上界。试验中的 FFT、平方根和浮点余量仅为数值近似，不能包装成机器严格认证。

对同一个折内候选与评分比较：(1) 无惩罚；(2) 原理论惩罚 ρ=1、0.1、0.05；(3) 局部上界惩罚 ρ=1、0.1、0.05。每个版本先按同一五折得分加惩罚选 r，再对五个折内估计求平均；真实密度只用于最终 ISE 评价。对原方法的四个版本要复核与已保存 ρ 敏感性结果的一致性。r=0 和 r=max 网格单独统计；按场景及 n 报告40次的 ISE、MCSE、相对无惩罚的配对差与配对 MCSE、r0 和 rmax 比例、局部上界平均值/原理论上界的比例。写出所有候选值、选阶、逐样本 ISE 及输入哈希；若输入不匹配或数值错误必须明确失败，不能静默删样本。

根据训练数据决定的 (A_{k,j}) 与该折验证样本条件独立；对候选及折使用条件 Bernstein/并集界，可以为 ρ=1 推出局部惩罚对应的 oracle 型界（待单独数学复核）；ρ<1 的抵消不完全，不能直接继承 ρ=1 的自适应界。模拟不能证明该界，也不能用真实密度或事后观察的最优 ρ 作为实际调参规则。
