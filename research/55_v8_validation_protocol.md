# v8 定向补充模拟方案

日期：2026-10-28。依据 v7 已观察结果和三份外部模型审稿意见制定，属于事后设计，非盲法预注册。

对双峰及尖峰、n=100和500各新增20组样本，种子 `SeedSequence([2026102821, scenario_index, n, rep])`，保留全部样本与折分配。每组共享五折，证书法、网格修复和完整 SDP 沿用 `fair_baselines.py` 的估计器和选参网格、η=0.1；外加直接 Fejér 核估计，其次数网格为 [0,1,2,3,4,6,8,12,16,24,32,48,64,96,128]，各自以同一五折 L2 损失选参后全样本重拟合。不同方法的候选参数有不同的含义和范围，比较为指定算法加调参规则的有限模拟比较，不是公平性或普遍最优的证明。

优先报告新批次20次及配对MCSE；与既有同方案主模拟40次合并仅用于数值精度描述，保留批次标签，须说明方案受既有结果启发，不能将60次当作事先独立设定的盲法验证。Fejér KDE 对照通过重建旧40组样本与原折来获得，因此也属于事后补算。汇报独立40和20批次均值、合并60的配对差、边界命中率、失败、全部原始数据；真实密度不参与调参。

失败以阶段与异常记录，不将失败排除后视为完整无条件结果；如失败，合并结果明确有效数并限制解释。保存每折评分和最终拟合诊断。完整SDP浮点PSD修复及证书法误差界均非严格机器认证。真实 Fourier 尾项使用 v7 中相同界，不能将浮点舍入纳入该界。进行独立复算检查样本、折、Fejér候选与汇总；它不等于重新求解全部QP或SDP。
